# Foundation Deep Learning Framework for Multiclass Alzheimer's Disease Classification Using Brain MRI Images

## Overview

This repository contains the implementation of the research paper:

**"A Foundation Deep Learning Framework for Multiclass Alzheimer's Disease Classification Using Brain MRI Images."**

The project presents an automated deep learning framework for classifying Alzheimer's disease into four stages using brain MRI images.

---

## Dataset

The experiments were performed using the publicly available Kaggle Alzheimer's Disease Multiclass Images Dataset.

Dataset Link:
https://www.kaggle.com/datasets/aryansinghal10/alzheimers-multiclass-dataset-equal-and-augmented

---

## Models Implemented

- Baseline Convolutional Neural Network (CNN)
- ResNet50 Transfer Learning Model

---

## Performance

| Model | Test Accuracy |
|--------|--------------:|
| Baseline CNN | 93.73% |
| ResNet50 | 98.82% |
